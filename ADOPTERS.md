# Adopters

This is an opt-in registry. Listing here is voluntary and collects nothing
automatically: the package has no telemetry and never phones home. If you use
the NC25OL and want to be listed, add yourself with
a pull request that appends one row to the table below.

Only add information you are willing to publish. Keep it minimal — an
organization or project name, an optional link, a one-line description of the
use, and the version you adopted. Do not add anyone else, and do not add
private deployment detail.

## How to add yourself

1. Fork the repository and edit this file.
2. Replace the placeholder row, or add a new row above it.
3. Open a pull request. The continuous-integration checks run automatically;
   the row is merged once reviewed.

Removal is the same process in reverse: open a pull request deleting your row,
and it will be removed.
